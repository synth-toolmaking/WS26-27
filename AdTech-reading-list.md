Controlled vocabulary (WIP)

- Ad Exchange: An automated digital marketplace that connects Supply-Side Platforms (SSPs) and Demand-Side Platforms (DSPs) to facilitate the buying and selling of ad impressions in real-time.
- ads.txt: A public text file hosted on a publisher's domain that declares which SSPs and exchanges are authorized to sell their inventory.
- Contextual Intelligence: The classification of URLs and page content into taxonomies, keyword densities, and sentiment categories to target ad placements without tracking individual users.
- Cost Per Mille (CPM): The industry-standard pricing metric representing the cost to purchase 1,000 ad impressions.
- Data Broker: An entity that continuously aggregates, categorizes, and sells third-party user data and associated behavioral signals to advertisers.
- Data Clean Room (DCR): A secure computational environment where an advertiser's first-party data is matched with publisher or DSP behavioral data to extract programmatic signals without exposing raw PII.
- Demand-Side Platform (DSP): The buy-side enterprise software engine used by advertisers to set budgets, define targeting parameters, evaluate bid requests, and execute real-time bidding algorithms.
- Deterministic Identity: A persistent tracking token derived from hard, authenticated user data, such as a cryptographically hashed email address or phone number.
- Header Bidding: A programmatic technique that initiates concurrent HTTP auction requests to multiple SSPs directly from the user's browser (or server) before calling the primary ad server.
- Identity Vendor: A B2B ad tech company that generates and manages persistent tracking tokens passed in the OpenRTB bid request to replace third-party cookies.
- Impression: A single, transient opportunity to display an ad to a specific user on a specific webpage at an exact moment in time.
- Line Item: The core unit of an ad campaign within an ad server, containing the targeting rules, price targets, and creative payloads required to execute an ad buy.
- OpenRTB: The global Real-Time Bidding standard and strict JSON schema maintained by the IAB Tech Lab that dictates how bid requests and responses are structured.
- Prebid.js: The open-source, industry-standard JavaScript wrapper implemented on publisher websites to facilitate client-side header bidding.
- Probabilistic Identity: A temporary tracking token generated by statistically modeling unauthenticated browser and network signals, such as IP addresses and user-agent strings.
- Publisher Ad Server: The foundational sell-side system that decides whether to serve a direct-sold campaign or an automated programmatic ad, and physically delivers the creative to the user's device.
- Supply-Side Platform (SSP): The sell-side enterprise software engine used by publishers to manage ad inventory, set floor prices, and send bid requests to external buyers.
- Transparency and Consent Framework (TCF) string: A cryptographic alphanumeric payload passed in the OpenRTB bid request that proves explicit user consent for specific vendors to process data under GDPR.
- Walled Garden: A closed advertising ecosystem where a single entity (e.g., Google, Meta, Amazon) controls the proprietary publisher inventory, the buy-side tools, and the sell-side ad server.
